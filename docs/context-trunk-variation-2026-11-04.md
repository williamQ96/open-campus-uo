# Context tree trunk variation — 2026-11-04, local only

The existing 300 inferred trees in `campus-trees` now receive a restrained trunk taper and deterministic bark-color variation. The original octagonal trunk bases, centers, heights and maximum diameter stay fixed; upper radii are 78% of the 0.15 m base radius. Each tree's original bark color is multiplied by a stable factor within ±6%. No trees are added or moved, and no canopy position, normal, color, index, collision or navigation data changes. These are generic stylized trees, not species identification or a field survey. ENV-02 remains level 1.

The [UO Atlas of Trees](https://cpfm.uoregon.edu/sites/default/files/treeatlas.pdf) documents the diversity of the campus collection, and [OSU Extension's western Oregon plant list](https://extension.oregonstate.edu/sites/extd8/files/documents/1/nativeplantreclist.pdf) gives regional context for varied bark. Neither source establishes the modeled tree locations, exact shapes or colors; the parameters are artistic inference. No reference imagery or third-party geometry is included. Original parameters and model output are CC BY 4.0; code is Apache-2.0.

[Before](images/context-trunk-varied-before-2026-11-04.png), [after](images/context-trunk-varied-after-2026-11-04.png) and [PBR](images/context-trunk-varied-pbr-2026-11-04.png) show the same first-person location with activity disabled. This is one local software-rendered view, not a campus-wide site survey. In the matched toon view, calls stayed 39 and triangles stayed 749,989; the fixed overview remained 178 calls under the unchanged <180 limit. The variation clones the existing 55,200-vertex geometry and index during loading, causing transient CPU memory and one-time computation; no hardware frame-time or peak-memory benchmark was performed.

The [parameter file](../apps/web-preview/public/scene/context-trunk-variation.json) is applied by [context-trunk-variation.js](../apps/web-preview/src/context-trunk-variation.js) after the existing source-pinned octagonal-trunk pass. The second pass validates the source hash, mesh identity, topology, original bark colors and all 300 generated trunk rings before cloning. It changes only the added trunk vertices; wrong inputs reject before replacement. The source campus GLB remains unchanged. A metadata-only preservation simulation carries the two tree layers only for the same source hash; no full scene rebuild was run.

The new [standalone GLB](../assets/vegetation-refinement/context-trees-varied-2026-11-04.glb) includes the runtime octagonal trunks plus this variation, with 55,200 positions and 72,000 indices in one project-coordinate mesh. It excludes terrain, collision and pilot trees, and is not 300 separately editable objects. The [previous standalone export](../assets/vegetation-refinement/context-trees-refined-2026-11-04.glb) is preserved and tested against the original refinement pass. New export/reimport position, normal and color errors were zero; index data matched exactly. A browser independently compared runtime and exported geometry, source hashes and a 512 × 512 PBR render. The existing Blender snapshots predate both refinements; no new `.blend` was generated. To reproduce the new standalone version, run `node scripts/export-context-trees-varied.mjs ../../assets/vegetation-refinement/<new-name>.glb` from `apps/web-preview` with local Vite running; the exporter refuses overwrites.

Validation passed 139 JavaScript tests, 22 Python tests, six targeted browser tests including the existing unchanged canopy-preservation and prior-export checks, production build, formatting, 154 archived source/model hashes, viewer override hashes and the 1,081-row inventory check. The existing build chunk-size warning remains. All work is local and unpublished.
