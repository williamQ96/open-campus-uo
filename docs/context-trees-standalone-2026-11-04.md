# Standalone refined context-tree batch — 2026-11-04, local only

The [independent GLB](../assets/vegetation-refinement/context-trees-refined-2026-11-04.glb) contains the existing 300 inferred `campus-trees` and the octagonal trunk refinement previously applied only at runtime. It is one indexed, vertex-colored mesh in the original project glTF coordinate frame, not 300 editable tree objects. Positions and canopy shapes are unchanged. It includes no ground, collision, navigation, pilot-tree batches or campus scene, and it does not assert real tree positions or species. ENV-02 remains level 1.

The [UO tree resources](https://cpfm.uoregon.edu/trees) document the campus tree collection as background; no UO GIS geometry or photograph is incorporated. These context trees are inferred beyond the limited 2024 pilot imagery. Model output is original CC BY 4.0; generator code is Apache-2.0. The original campus GLB and the Blender files remain unchanged, and no matching per-tree Blender snapshot was produced. The GLB carries standard PBR material and vertex colors; the application's Toon adaptation, lighting, fog and surroundings still require the consuming application.

The reusable `apps/web-preview/scripts/export-context-trees.mjs` checks the exact base GLB hash and runtime parameter hash, loads the existing source mesh, applies `src/context-trunks.js`, and refuses to overwrite an existing output. It checks source files again before writing. Reimport comparison found zero error for all 55,200 positions, normals and colors and exact agreement for all 72,000 indices; one identity-transformed mesh and source hashes were also verified. A local browser test independently loads the written GLB, compares it against the runtime source and obtains an identical 512×512 offscreen PBR render at one camera. That view is not a full-scene or device performance benchmark. No runtime mesh, tree placement, canopy test threshold or performance threshold was changed.

Reproduce from `apps/web-preview` with the local Vite server running: `node scripts/export-context-trees.mjs ../../assets/vegetation-refinement/<new-name>.glb`. It produces a snapshot of the 300-tree batch, not a complete rebuilt campus or independently editable Blender scene.

Validation passed 132 JavaScript unit tests, 19 Python preservation/reference tests, five browser tests, production build, formatting, viewer hashes and 139 archived asset records. A metadata-only simulation preserved 44 exterior layers and confirmed the Hayward study is absent from the active scene; no full Blender rebuild was run. The existing large-chunk build warning remains.
