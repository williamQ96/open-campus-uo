# Knight Law Center western exterior study — 2026-11-04

The [UO architecture guide](https://expo.uoregon.edu/spotlight/history-uo-architecture/feature/william-w-knight-law-center) identifies the William W. Knight Law Center at 1515 Agate Street. The archived UO campus reference map places Agate Street west of the building. [Rick Obst's 2010 photograph](https://commons.wikimedia.org/wiki/File:Knight_Law_School_on_the_University_of_Oregon_Campus.jpg) explicitly describes a view from Hayward Field across Agate Street, so it supports the west-facing orientation and shows brick, light window surrounds, a large arch and repeated gables. The photo is CC BY 4.0; it is linked for reference only and neither pixels nor third-party geometry are embedded.

`roof-f52041e8` is an approximate-nearest-roof match in the project's historical LiDAR-derived scene; its outline is irregular and may include canopy or omit courtyard features. A source-pinned wall recolor changes 424 matching vertical vertices to an illustrative brick tone, leaving the original GLB and roof surfaces intact. Reversible building-detail JSON adds 15 schematic window groups to five sampled west-wall sections and two small brick gable forms inspired by the photo. Source wall positions were ray-sampled at multiple points; a check against 80 original glass quads found no projected overlap with these new windows. The large public-art entrance arch, artwork, signage and landscape were not reproduced. [West before](images/knight-law-west-before.png) / [after](images/knight-law-west-candidate.png); [east before](images/knight-law-east-before.png) / [after](images/knight-law-east-candidate.png).

This is a partial study, not a surveyed reconstruction. The exact footprint and geometry, building heights, gable count and positions, entry, glazing, actual roof surfaces, other elevations, plantings, paths and present condition are unverified. Some original generic windows remain; the flat source roof remains visible. Keep level 1. These additions do not alter the interior, building selection identity, original GLB, terrain, vegetation or navigation data. The JSON specifications are the editable runtime inputs; the original standalone GLB and Blender snapshot do not contain these changes and require the overlay for this appearance.

Detail is merged into the source-pinned compatible building mesh after checking its 6,200 source vertices and material contract, avoiding a separate draw call while reducing separate culling within this building. Conservative ENU rectangles around the added window areas were checked against route graph edges with 0.5 m margin and yielded zero intersections; this does not establish physical clearance or accessibility. Source-pinned rebuild checks must still pass after upstream changes. Original overlay data are CC BY 4.0. Runtime code is Apache-2.0. Visual scene review, browser selection in toon and PBR, the existing activity-disabled draw-call budget, unit tests and build were checked; no hardware performance benchmark is claimed.
