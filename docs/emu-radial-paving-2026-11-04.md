# EMU forecourt radial paving — 2026-11-04, local only

The existing pilot `landscape-paving` material now renders an illustrative circular, staggered paver pattern within an approximately 9 m radius of glTF x/z (-277, 31), west of the Erb Memorial Union. The treatment fades into the existing square-joint material; no paving mesh, terrain, height, building, stair, entry, navigation or collision geometry is added or changed. The [2017 EMU exterior photograph by Daderot](../data/reference-images/photos/erb-memorial-union/exterior-2017.jpg) shows a circular paved forecourt and was already archived as CC0 in the [reference manifest](../data/reference-images/manifest.json). The [2024 USDA NAIP pilot reference](../data/metadata/naip-2024-reference.json) provides a dated aerial cue for its approximate position. Neither establishes current conditions or a surveyed center, dimensions, brick size or joint pattern. Ring spacing, stagger and transition are original visual approximations rather than a reconstruction of individual stones. ENV-05 remains level 1.

[Before](images/emu-radial-before-2026-11-04.png), [after](images/emu-radial-after-2026-11-04.png) and [PBR](images/emu-radial-pbr-2026-11-04.png) use the same 1440 × 1000 first-person position with activity disabled. The existing model's block-like steps and grades remain approximations and do not match all features in the photograph. Before and after both recorded 71 draw calls and 819,257 triangles. A separate fixed overview remains 178 draws, below the unchanged <180 budget. The shader adds per-fragment arithmetic; these software-rendered views do not measure hardware frame time or accessibility.

The editable parameters are in [pilot-paving-joints.json](../apps/web-preview/public/scene/pilot-paving-joints.json) and the shader in [paving-joints.js](../apps/web-preview/src/paving-joints.js). The existing source hash, unique mesh, material and vertex-count guards remain in place; the optional radial parameters have additional bounded validation and a distinct shader cache key. Prior [parameters](../assets/exterior-refinement/paving-joints-before-emu-2026-11-04.json) and [code](../assets/exterior-refinement/paving-joints-before-emu-2026-11-04.js) are retained. The source campus GLB and Blender snapshots are unchanged: neither standalone file contains the runtime shader. Reproduction requires the pinned source GLB, parameters, presentation configuration and runtime code; no baked GLB or new Blender snapshot was produced.

Validation passed 141 JavaScript tests, 22 Python tests, six browser tests, production build, formatting, viewer hashes and 155 archived source/model files. Browser checks compare all 534 entrance records, modeled collision and an unrelated image crop before/after; they also check navigation, PBR and the existing draw limit. A metadata-only preservation simulation carried the updated paving layer, and the inventory parsed as 1,081 rows. The build retains its large-chunk warning. No full Blender rebuild or device performance benchmark was performed; changes remain local and unpublished.

## North background landcover screen

The archived 2024 main-campus aerial also revealed some northern upland shadows classified as `water-cue` by the existing coarse ground classifier. An isolated candidate to recolor 792 such vertices in a screened far-north rectangle passed a source/geometry check, but the area's existing spatial haze made the change barely visible in an in-scene review. It was not integrated or exported; no river shoreline or source GLB changed. The candidate files remain outside this project in the local task workspace for future review. Other dark linear features can be real water, so this screening is not a license to relabel every dark area. Further work requires clearer visual goals, careful boundary review and performance validation.
