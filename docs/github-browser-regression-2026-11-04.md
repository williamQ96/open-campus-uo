## Local diagnosis and bounded movement candidate

The trace's 4.048 m equals eleven render updates at the 4.6 m/s sprint speed and the previous 0.08 s per-frame clamp (11 × 4.6 × 0.08). The sampled coordinates advanced throughout the interval rather than stopping at an obstacle. This strongly supports lost movement time at very low frame throughput as the cause of this failure, although it does not rule out collisions on other routes. A local browser reproduction throttled animation callbacks to approximately one per 900 ms: the original implementation reached 5.520 m and failed the unchanged >6 m / 15 s assertion.

A local candidate allows horizontal movement to use up to 0.25 s per visible render frame, while retaining the original 0.08 s cap for vertical physics and other animation. Existing movement collision checks still subdivide each move, and hidden tabs get no movement time. Unit tests cover the time bounds and a wall; the unchanged navigation suite and the slow-frame reproduction pass locally. This is bounded compensation, not a rendering-performance fix or full wall-clock catch-up: at one frame per second it simulates at most 0.25 s of movement per frame, and movement, vertical physics and animation can progress at different rates in slow frames. The cause of the runner's poor frame throughput remains to be investigated.

The candidate and the Ford exterior work remain local and unpublished. GitHub's full browser suite has not been rerun against this candidate; its published result remains 90 passed and one failed.

During additional mobile regression the first candidate incorrectly classified slow analog walking as running because it divided the compensated displacement by the old 0.08 s animation step. The candidate was adjusted to calculate running speed using the same movement time as the displacement; after this correction, all eight mobile, original navigation and simulated slow-frame browser tests passed. The other six comfort, Ford and visual-pilot browser checks in the earlier run passed; the two mobile failures in that earlier run were the issue corrected here. All 117 unit tests, production build, formatting and viewer override hashes passed locally.
