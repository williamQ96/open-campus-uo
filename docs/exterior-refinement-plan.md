# Exterior refinement: working plan

Status: 2026-11-03. This plan covers exterior assets only. The inventory remains the authoritative per-asset status; do not change interior entries in this work.

## Baseline and scope

The existing inventory contains 1,081 rows: 534 exterior building identities, 534 planned individual interiors, and 13 shared/environment/life entries (some are not exterior). Knight Library is the user's level-2 example; the other 533 existing building exteriors and existing environment assets remain level 1. A modeled building identity is not necessarily a verified present-day UO building: 63 have names, and 471 are unidentified. Confirm identities and duplicates before adding names or making site-specific claims. Retain the current campus layout and isolated landmark and vegetation patches.

## Proposed working comparison — not an approved level definition

Compare each candidate with the current Knight example: recognizable massing and silhouette; photo-supported main elevations, roof and distinctive features; consistent Architectural Toon palette, materials and scale; visual integration in the surrounding terrain and plants; clear records of inferred or hidden elements; and working selection, rendering, performance and rebuild. Compare vegetation, landscape and props using their own regional form, scale, materials and context rather than imposing building features. Use dated, attributable references with documented reuse permissions. This is a working checklist only, not a user-approved level-2 standard. Promote an individual asset only after evidence and review support a genuinely comparable result; otherwise leave its actual recorded level. Levels 3–5 remain undefined.

## Prioritized batches

1. Maintain the Knight/EMU/Johnson focus area first: reconcile known tree/building intersections against photographs before moving trees; preserve the source-pinned tree 273 correction and underlying generated scene. Address remaining 129/296 and shared ground/understory gaps individually with evidence.
2. Group named buildings into walkable regions: academic core and business complex, science and education, arts and recreation, residences and east campus. Establish identity and usable exterior reference for each; refine a small set at a time without regenerating unrelated landmarks. Check multi-view context and record every approximation.
3. Classify remaining unnamed roof/context identities with project data and official sources. Distinguish historical survey footprints, outbuildings, duplicates and vegetation; leave unverified identities anonymous. Work by region with bounded changes, avoiding imagined departments or facades.
4. In parallel with each regional batch, improve its trees, ground surfaces, paths, furniture and transport props using reusable generators. Preserve positions unless references support a change. Record source/license, scene screenshots, runtime checks and remaining gaps under the existing 13 inventory IDs; do not equate one improved instance with a completed category.
5. Per batch run relevant asset/rebuild checks, viewer override hash check, browser context and mobile checks, plus build and tests. Update the inventory only for work actually verified; log no geometry change as an upgrade. Keep all work local until publication is authorized.

## Building information batch

A separate data file associates 32 existing stable building IDs with sourced basic purposes or known occupants from official UO pages, checked 2026-11-03. Source links and date appear on the card. Known occupants are partial, not a complete tenant directory; absent or unavailable data are explicitly unknown. This is information coverage, not an exterior geometry refinement or a level promotion. Remaining identities require source-by-source verification. Official pages are linked as references; no external photographs or models are bundled in this batch.
