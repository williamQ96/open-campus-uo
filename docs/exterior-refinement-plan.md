## Baseline and scope

The existing inventory contains 1,081 rows: 534 exterior building identities, 534 planned individual interiors, and 13 shared/environment/life entries (some are not exterior). Knight Library is the user's level-2 example; the other 533 existing building exteriors and existing environment assets remain level 1. Confirm identities and duplicates before adding names or making site-specific claims. Retain the current campus layout and isolated landmark and vegetation patches.

## Proposed working comparison — not an approved level definition

Compare each candidate with the current Knight example: recognizable massing and silhouette; photo-supported main elevations, roof and distinctive features; consistent Architectural Toon palette, materials and scale; visual integration in the surrounding terrain and plants; clear records of inferred or hidden elements; and working selection, rendering, performance and rebuild. Compare vegetation, landscape and props using their own regional form, scale, materials and context rather than imposing building features. Use dated, attributable references with documented reuse permissions. This is a working checklist only, not a user-approved level-2 standard. Promote an individual asset only after evidence and review support a genuinely comparable result; otherwise leave its actual recorded level. The upstream [maturity definitions](https://github.com/williamQ96/open-geospatial-to-3d-reconstruction-pipeline/blob/main/docs/zh-CN/asset-refinement-inventory.md#等级及适用范围) document L3 through L5 and the scope of the Knight example.

5. Per batch run relevant asset/rebuild checks, viewer override hash check, browser context and mobile checks, plus build and tests. Update the inventory only for work actually verified; log no geometry change as an upgrade. Keep all work local until publication is authorized.
