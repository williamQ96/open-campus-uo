# Pilot planting shared-material fix — 2026-11-04, local only

The 40 existing inferred shrubs in the `planting` mesh (a 16-shrub band and a 24-shrub ring in the original generator) no longer render black when the pilot canopy-tone patch is active. This restores their existing green source material in Architectural Toon and PBR. No plant positions, geometry, species, tree crowns, terrain, collision or navigation were changed; this is a rendering correction rather than a vegetation survey. ENV-03 remains level 1.

The base GLB shares its `leaf` material between `vegetation_2` and `planting`. The canopy-tone patch previously enabled vertex colors on that shared material, but `planting` has no color attribute, making the shrubs black. `src/canopy-tone.js` now clones each selected canopy material before enabling vertex colors. Other users of the original material retain their unchanged material and color. Canopy tone values and the existing canopy tests and thresholds were not changed. Validation rejects bad patch input before assigning the cloned materials.

The [2024 USDA NAIP pilot source record](../data/metadata/naip-2024-reference.json) provides dated broad vegetation context; it does not identify these modeled shrubs or verify their locations. [Oregon State University's regional native-plant guide](https://extension.oregonstate.edu/catalog/em-9697-incorporating-pacific-northwest-native-plants-your-water-wise-landscapes) gives general shrub context; this correction does not claim a specific plant species. No reference pixels or third-party geometry are embedded. Code is Apache-2.0 and original assets are CC BY 4.0.

Matched activity-disabled first-person screenshots show [before](images/shrub-band-before-2026-11-04.png), [after in Toon](images/shrub-band-after-2026-11-04.png) and [after in PBR](images/shrub-band-pbr-after-2026-11-04.png). Toon before and after each reported 85 draw calls and 824,803 triangles. Cloning three material objects adds minor CPU/material state; the sample is not a hardware frame-time benchmark. The source GLB and Blender snapshot were not altered, and no new asset or Blender export is required for this runtime fix. The base GLB alone retains the original green material; consumers applying the canopy-tone layer must use the corrected runtime code. Plant shapes, positions, current conditions and species remain inferred.

Validation passed 133 JavaScript unit tests, 19 Python preservation/reference tests, six targeted browser tests, production build, formatting, viewer hashes and 139 archived asset checks. A metadata-only preservation simulation carried all 44 exterior layers; a full Blender rebuild and hardware frame-time benchmark were not performed. The build retained its existing large-chunk warning.
