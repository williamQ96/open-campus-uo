# Standalone pilot lamp detail overlay — 2026-11-04

The 40 existing source-pinned bases, supports and caps at eight inferred globe-lamp positions now have a [standalone GLB](../assets/exterior-refinement/pilot-lamp-overlay-2026-11-04.glb). This is an export/reuse improvement only; no new lamps were placed and the runtime scene and PROP-01 level 1 remain unchanged. The generic form was informed by the archived [Anstett photograph](https://commons.wikimedia.org/wiki/File:Anstett_Hall,_University_of_Oregon,_Eugene_-_DPLA_-_7f05aff2c79e236edd0bed0104b6f145.jpg) (Gary Halvorson/Oregon State Archives, CC BY 4.0), not a survey of these fixtures. No photo or third-party geometry is embedded. Original model output is CC BY 4.0; code is Apache-2.0.

The export is one mesh in campus coordinates and contains **only** the added components, not the original poles or globes, collision, or full campus. Its 3,840 positions, normals and vertex colors match the generated layer exactly; its positions also match the vertices appended into the original metal batch. The exporter checks that the overlay color matches the existing target material and copies its double-sided and PBR parameters. The runtime performs this merge with the original source geometry; do not add the standalone GLB on top of the already refined campus. The [existing runtime view](images/pilot-lamps-after.png) includes original lamps that are absent from the standalone file. Actual placement, ground contact and access are unverified; three other ambiguous lamp positions remain untouched. No new Blender snapshot was made; the JSON and procedural generator remain the editable source.

With local Vite running, reproduce from `apps/web-preview`: `node scripts/export-environment-detail.mjs pilot-lamp-detail.json ../../assets/exterior-refinement/<new-name>.glb`. The reusable exporter supports only pinned, non-replacing environment prop layers comprising boxes and columns; it rejects unsupported geometry, changed source, source GLB, generator or presentation hashes, material mismatch, and existing output files. It bakes source rotations using the runtime generator. It does not claim support for all environment shapes or create per-component Blender objects.

[Isolated side-by-side comparison](images/lamp-overlay-comparison-2026-11-04.png): runtime-generated detail left, GLB right. The floating pieces show why the export is not a complete lamp. Validation passed 125 Node tests, 16 Python tests (including two GIS-screen tests), production build, formatting, viewer hashes, 127 archived asset checks and five browser tests for lamp export, scene loading and navigation; the on-disk export test was rerun after material alignment. The existing fixed-camera draw-call threshold passed. No full scene rebuild or device performance benchmark was performed.
