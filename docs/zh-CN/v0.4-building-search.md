# v0.4 — 出生点与建筑搜索

出生点为用户截图所指的 University Street / East 13th Avenue T 字路口：局部 ENU `[-305.469651, 0.824825]`，取自现有两条道路中心线的交点。点位距最近建筑轮廓约 21.70 m；角色、首次跟随与第一人称朝向对准 Erb Memorial Union。Return to start 会清除搜索选择并恢复这个位置和朝向。

`configs/eugene-main-campus.json` 保存出生点及 viewer 的朝向目标。`scripts/rebuild.ps1` 生成浏览器 `public/scene/viewer-settings.json`；UO 镜头偏好保留在 downstream，upstream 仍固定 v0.3.0。已按锁定的干净 upstream 完整重建核验，几何与 GLB 未改变。Blender 文件的纯保存时间差未纳入本次内容修改。

## 搜索行为

- 页头下左侧提供全英文搜索框。窄屏布局保留搜索、视角按钮和设置入口。
- 当前搜索 63 个已命名建筑；支持不区分大小写、名称片段、多词检索及首字母缩写，如 EMU、PLC。不为未识别结构虚构名字。
- 搜索框聚焦时停止移动输入。上下方向键选择，Enter 定位；点击结果也可定位。无匹配时明确提示，不改变角色位置。
- Overview 保持当前水平观察方向，以约 45° 俯角和适合建筑大小／屏幕比例的距离展示。使用 650 ms 过渡；减少动态效果设置下直接定位。手动拖动或滚轮可打断过渡。
- Follow / First person 保持角色位置，转向建筑并高亮模型与标签。移动或拖动后交还手动镜头控制；高亮选择仍保留。
- 切换视角保留搜索目标，按新模式重新定位；Follow 滚轮缩放仍可使用。
- 选中标签优先于普通标签，关闭普通建筑标签时仍显示选中标签。边缘标签会钉在可视区并用箭头指示方向；小地图以金色环标记目标。
- Esc 关闭候选列表；不在输入框时 Esc 可清除选择。清除按钮取消选择并继续搜索，不传送角色或强制退回总览。
