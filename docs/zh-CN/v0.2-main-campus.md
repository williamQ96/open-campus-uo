# v0.2 — Eugene main campus

本次将 Memorial Quad 闭环扩为主 Eugene 校园及周边 2 × 2 km 的矩形场景。它包含主要教学区、宿舍区、体育设施与北侧校园区域；范围不是官方用地产权边界，也不包括河以北的 Autzen Stadium complex。

固定版本最终产物：裁剪 32,105,518 个点，其中 7,565,189 个地面点；534 个结构体块，63 个名称记录，其中 17 个显式近似 envelope。5 m 地形网格内部留出插值 RMSE 为 0.2412 m，不代表独立测量精度。完整记录见 `data/metadata/main-campus-audit.json`。

## 可见变化

- 以 canvas-design 技能制作原创 OpenCampus 标志，交付透明图标、字标、PNG 品牌页和 PDF。设计理念见 `design/open-campus-philosophy.md`；页面已使用实际标志和 favicon。
- UI 全英文；移除左侧标题、标语和数据面板。资料集中到 Settings / About。
- 中性偏灰地面，与白色建筑明确区分。
- Space 起跳，重力下落并贴合真实地形；只允许落地后再次起跳。WASD/Shift 与三种视角仍可使用。
- 已命名建筑使用 roof-anchored CSS2D 标签，始终面向相机，并按屏幕重叠情况隐藏部分标签以保持可读性。

## 来源与语义

地形和历史体块使用 9 个 NOAA/DOGAMI OLC 2008 瓦片，固定 SHA-256，具体选择见 `configs/eugene-main-campus.json`。原 Memorial Quad 配置和 Blender 产物保留。

建筑名称来自公开 UO 建筑名录及公开校园地图中的事实性名称。`data/metadata/campus-buildings.json` 保存独立的近似定位点、匹配方式和来源。定位点以公开 Census 路线位置作粗略校准；不导入 UO GIS 多边形或内部数据。

名称定位与屋顶匹配仍属近似；落入同一 footprint 不等于完成独立身份测量。未识别的城市周边体块不虚构校方名称。航测后的建筑与漏提取屋顶采用显式近似 envelope，并在 Blender/GLB 元数据中标识。它们不是实测建筑复制品。

2023 OLC 调查报告及 Autzen 示例 clip 已被发现，但未并入本产品。当前仍为历史几何基线加独立近似内容，不能当作精确的 2026 校园测绘。

## 工程边界

upstream v0.2 提供通用多瓦片处理、注释匹配、近似 envelope、材质配置和来源校验；UO 名称与具体模型参数留在 downstream。下游锁定 upstream commit 后重建。

运行时将未命名环境几何合批，保留原始 Blender 独立对象；建筑仍使用独立语义信息与碰撞轮廓。静态建筑阴影只在必要时更新，小地图背景缓存，避免扩图后每帧重复工作。

## 复跑

在本仓库运行 `./scripts/rebuild.ps1`，默认使用 `configs/eugene-main-campus.json`。可通过 `-Config configs/memorial-quad.json` 重新生成旧试验区；这会切换当前浏览器场景，因此应有意执行。

预览仍是 `apps/web-preview` 下的 `npm ci`、`npm run dev`。测试包括上游语义匹配、跳跃物理、全英文界面、主校区范围、标签投影/相机正向、桌面与窄屏交互。完整结果以提交后的 CI 和场景 `quality` 为准。

本地最终检查：8 项上游 Python 测试、6 项移动/跳跃单元测试、4 项真实浏览器集成测试均通过，生产构建通过。图标透明通道、文档链接、源文件与 GLB 校验和、534 个唯一资产 ID、注释文件 hash 和 clean upstream pin 均已核对。
