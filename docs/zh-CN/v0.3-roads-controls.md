# v0.3 — 基础路网、Follow 缩放与项目链接

已在同一个 2 × 2 km 场景加入 140 段裁剪后的中心线（132 段道路、8 段步行／自行车路径）。主要街道包括 Franklin Boulevard、Kincaid、University、Agate、13th、15th、18th Avenue 等；来源名称与 LINEARID 保留。Blender 和 GLB 均包含独立道路／路径图层，小地图同步显示。

## 道路来源与范围

来源为美国 Census Bureau 的 [2025 TIGER/Line® Lane County All Roads](https://www2.census.gov/geo/tiger/TIGER2025/ROADS/tl_2025_41039_roads.zip)。[官方技术文档](https://www2.census.gov/geo/pdfs/maps-data/data/tiger/tgrshp2025/TGRSHP2025_TechDoc.pdf) §1.2 说明政府数据可复制，并请求注明 Census Bureau 来源；About 已署名，未将其商标用于本项目名称。

`scripts/build-campus-roads.py` 校验县级原始 ZIP 的 SHA-256，核对 NAD83 / EPSG:4269 的 .prj，投影并裁剪至场景周边，输出 `data/metadata/campus-roads.geojson`。复跑使用 upstream Python 环境和 `pyshp==3.1.6`。源 ZIP 保存在忽略的 `data/raw`，不复制 UO 内部 GIS 或商业地图数据。

路宽按道路类型估算，约 3–18 m。通用 upstream v0.3 合并路口、排除建筑覆盖、裁切 AOI，再按原地形每一个三角面生成路面，抬高 4 cm 避免闪烁。路面高度来自历史地形，不是新增测量。不同道路类型不保证当前通行权；校园内部步道覆盖仍不完整。本版没有桥面、精确路缘、车道标线或路由网络。

## 镜头与 About

- `1 · Follow` 下向上滚轮拉近，向下拉远；距离限制 2.5–30 m，平滑过渡并保留建筑避障。
- 第一人称不会被滚轮改变；鸟瞰沿用既有 OrbitControls 缩放。切换视角保留跟随距离，Return to start 恢复 7.5 m。
- About 直接链接 [Open Campus: UO](https://github.com/williamQ96/open-campus-uo) 与 [Open Geospatial-to-3D Reconstruction Pipeline](https://github.com/williamQ96/open-geospatial-to-3d-reconstruction-pipeline)，说明长期下游内容与上游方法分工，以及 private 访问限制。

## 验证证据

先用 360 × 360 m Memorial Quad 配置成功重建含 7 段道路的 Blender/GLB 小场景，再推进 `pipeline.lock.json`，从全部 9 个已校验 LiDAR 瓦片重新生成主校区。原有地形、534 个体块和 63 个名称保持不变。

本地 11 项 upstream Python 几何测试、6 项移动／跳跃单元测试、5 项真实浏览器集成测试全部通过。新增检查包括非共面坡地上的路面三角形一致性、孔洞、建筑排除、路口去重、实际 GLB 道路节点、About 链接、滚轮远近变化与上下限、视角切换、设置面板和复位。格式检查与生产构建通过。

当前路网及模型 hash 见 `data/metadata/roads-audit.json`；`data/metadata/main-campus-audit.json` 保留 v0.2 历史地形／建筑基线证据。当前完整来源与版本在浏览器 `public/scene/manifest.json` / `sources.json`。截图保存在忽略的本地 `artifacts/eugene-campus-overview.png` 等文件中。
