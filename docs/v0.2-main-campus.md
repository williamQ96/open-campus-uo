# v0.2 — Main Eugene campus

The original Memorial Quad loop was expanded into a 2 × 2 km square covering the main academic campus, residences, athletic facilities and northern campus context. It is not an official property boundary and excludes the Autzen Stadium complex north of the river.

The pinned build cropped 32,105,518 points, including 7,565,189 ground points, from nine NOAA/DOGAMI OLC 2008 tiles. It generated 534 structural placeholders and 63 named records; 17 envelopes explicitly supplement post-survey or unextracted structures. The 5 m ground grid has an internal holdout RMSE of 0.2412 m, not independently surveyed absolute accuracy. [The audit](../data/metadata/main-campus-audit.json) preserves that generation baseline.

The release added an original OpenCampus identity, English UI, grey ground, Settings / About instead of the introductory panel, jumping, and roof-anchored screen-facing name labels with overlap decluttering. Unnamed runtime geometry is batched while editable Blender objects remain separate. Static shadows and a cached minimap background reduce repeated work.

Names and approximate anchors use public building facts and the campus map, with independent coarse locator calibration. UO GIS polygons are not imported. Name-to-roof matching still needs independent verification. Explicit modern envelopes are approximate content, not LiDAR measurements. The original Quad configuration and Blender asset remain available.

A 2023 OLC survey report and Autzen example clip were discovered but not integrated. This release is a historical baseline with approximate additions, not a precise 2026 survey.

The upstream v0.2 work added generic multi-tile handling, annotations, envelope matching, materials and source validation. UO identities and dimensions stayed downstream. Eight upstream tests, six movement/jump tests and four browser tests passed locally at that milestone; later records describe additional checks and the public site.
