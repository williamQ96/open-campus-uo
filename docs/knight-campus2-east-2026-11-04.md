# Knight Campus Building 2 east facade — 2026-11-04

[ZGF, the project's architect](https://www.zgf.com/work/9716-university-of-oregon-phil-and-penny-knight-campus-for-accelerating-scientific-impact-building-2), describes an east bar along Riverfront Parkway, four floors with protected glazing and exterior fins, and an offset building mass. The [UO building page](https://knightcampus.uoregon.edu/building-2) gives a north–south length of 353 ft, approximately 107.6 m. A [UO 2026 exterior photograph](https://www.uoregon.edu/press/2026/knight-engineering/) was used as a visual reference; it is linked only, not bundled or used as a texture. Original overlay data are CC BY 4.0.

The existing `context-oc-knight-2` is a 75 × 85 m rectangular approximate context envelope with an approximate public-map label anchor, not a surveyed building footprint. Its 85 m north–south span is materially shorter than UO's published length, and it lacks the building's two offset bars. A reversible, source-hash-pinned overlay adds an illustrative opaque-glass east face, four-level horizontal bands and repeated vertical light-metal fins to that existing envelope. It does not correct the building mass, model its interior, reconstruct its detailed fins, change the other three elevations, or add the nearby skybridge, pool, landscaping or roads. [Before](images/knight-campus2-east-before-2026-11-04.png) / [after](images/knight-campus2-east-after-2026-11-04.png). Other generic buildings partly block the view of this face. The apparent location, height, facade segmentation, roof, precise dimensions, site relationships and actual surroundings remain unverified. Keep level 1.

The overlay adds 49 boxes in one merged building mesh and retains the stable selection ID. Four thin, footprint-adjacent collision boxes cover the added face; no existing route-graph segments intersect them with a 0.5 m margin. This is a limited screen, not a field survey or accessibility assessment. No base GLB, vegetation, terrain, building position or interior is changed.

`apps/web-preview/public/scene/knight-campus2-east-detail.json` is the editable runtime source, with the layer and base GLB hash pinned in `presentation.json`; the existing rebuild guard retains it only for matching hashes. The original standalone GLB and old Blender files do not include the overlay. No new Blender snapshot was produced, because Blender was not found and installation was explicitly excluded; the existing reusable box-overlay exporter is available for a later snapshot.

Validation: source pin, building ID, single merged mesh, collision contracts and route screening; 120 Node tests, 14 rebuild-preservation tests, production build, 108 open-asset records and viewer hash checks. A five-test local browser batch checks this building and Jaqua selection in toon/PBR, original activity-disabled draw-call budget and navigation. The scene screenshots are visual model checks rather than evidence of present conditions; no hardware benchmark is claimed. All work remains local and unpublished.
