# Campus lawn extension tone — 2026-11-04, local only

The existing `campus-lawn-extension` mesh, previously outside the pilot-only treatment, now receives the same restrained procedural lawn-tone treatment in Architectural Toon and PBR. It is a broad, modest color variation, not new landscaping or a surveyed vegetation map. This mesh has 47,699 vertices and its bounding box spans approximately east -699 to 469 m and glTF south -359 to 604 m; the bounding box is not a claim that all enclosed land is grass. Existing geometry, vertex colors, terrain height, layout, navigation and collision are unchanged. ENV-04 and ENV-05 stay level 1.

The [UO Memorial Quad description](https://scheduling.uoregon.edu/rooms/memorial-quad) confirms lawn, shade trees and paths as general landscape context. The [2024 USDA NAIP source record](../data/metadata/naip-2024-reference.json) supplies dated context for the smaller pilot area only; neither source verifies the entire extension, grass species, color variation or current conditions. No source image or third-party geometry is included. Treatment parameters are original CC BY 4.0 and code Apache-2.0.

`pilot-lawn-tone.json` adds a source-pinned extension contract. Both meshes must match their expected names, vertex counts, source materials and asset hash before either receives a treatment; the extension's existing vertex colors remain active. A mismatched source is rejected, rather than partially styled. The standalone source GLB and existing Blender snapshot do not contain the runtime shader; the scene JSON and runtime code must accompany the GLB. No new Blender snapshot or baked export was made, and no full rebuild was performed.

At the same first-person camera near Cedar Hall, activity disabled, [before](images/extension-lawn-before-2026-11-04.png) and [after](images/extension-lawn-after-2026-11-04.png) each showed 39 draw calls and 766,752 triangles. The tonal change is deliberately subtle; shader calculations add fragment work, and this single software-rendered view is not a device frame-time benchmark. Existing performance thresholds were not changed. Validation: 130 JavaScript unit tests, production build and formatting, viewer and asset hashes, and four browser tests including toon/PBR and navigation. The build continues to report its large-chunk warning.
