# Pilot canopy tonal variation — 2026-11-04

A source-pinned, reusable presentation layer adds subtle deterministic light/dark variation to the three existing pilot-tree canopy material batches. It covers the 300 modeled pilot trees, of which two were previously suppressed (approximately 298 visible); the other roughly 300 campus trees use other batches and are unchanged. The [2024 USDA NAIP reference and metadata](../data/metadata/naip-2024-reference.json) are contextual evidence for the pilot area's broad vegetation distribution, not for the color, species or placement of an individual tree. Colors are an original visual treatment using the existing palette; no photo pixels or textures are sampled or embedded. Tree identities, coordinates, heights, crown geometry, species and current conditions remain inferred and ENV-01 stays level 1.

The editable parameter file `apps/web-preview/public/scene/pilot-canopy-tone.json` is directly loaded at runtime, while `apps/web-preview/src/canopy-tone.js` generates the color attributes. The optional layer is tied to the exact source GLB hash and checks the three mesh names, material names, colors, vertex counts and source transforms before any mutation; a mismatch rejects the whole operation. Source positions, triangles, trunk material and navigation do not change. The previous GLB and Blender source remain unchanged; exporting that standalone GLB alone retains its earlier uniform canopy colors, so the parameter layer and runtime code must accompany it for this appearance. Prior `presentation.js` is retained at `assets/vegetation-refinement/presentation-before-canopy-tone-2026-11-04.js`. Original code is Apache-2.0 and the parameter data CC BY 4.0.

Both are controlled presentation views. No image is embedded in runtime geometry. The change is color-only, not a refinement of tree silhouettes or a full campus survey.

The three batches contain 212,868 vertices. A temporary float RGB attribute adds 2,554,416 bytes of raw vertex data, plus runtime/driver overhead and one-time CPU computation. In two matched default-density software-rendered samples, both versions had 246 draw calls and 1,054,117 triangles; activity-disabled browser checks continue to require fewer than 180 calls. This is not a hardware benchmark or a guarantee of mobile performance. Both toon and PBR browser modes, source mismatch rejection, unit tests, build, scene navigation and source-pinned rebuild preservation were checked. The pre-existing tree/building overlaps, species, ground contact and accessibility remain unresolved.
