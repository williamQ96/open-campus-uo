# Pilot lawn material and bike-rack screening — 2026-11-04, local only

The existing `landscape-lawn` surface receives a subtle procedural, world-space tonal variation in Architectural Toon and PBR. Its authored mesh covers approximately east -644 to -145 m and glTF south -20 to 340 m, not the whole campus. Geometry, height, placement, collision and navigation are unchanged. This is an illustrative treatment, not a mapped planting pattern, species survey or measurement of grass color. ENV-05 remains level 1.

The [2024 USDA NAIP source record](../data/metadata/naip-2024-reference.json) provides dated, broad green-space context only. It does not verify this pattern or present conditions. The source imagery is US public domain; no pixels are incorporated. Parameter data are original CC BY 4.0; runtime code is Apache-2.0. See the same first-person view [before](images/pilot-lawn-before-2026-11-04.png), [after in toon](images/pilot-lawn-after-2026-11-04.png), and [after in PBR](images/pilot-lawn-pbr-2026-11-04.png).

The optional `apps/web-preview/public/scene/pilot-lawn-tone.json` pins the base GLB hash, unique mesh name, vertex count and original material. `src/lawn-tone.js` validates before marking it and applies the shader to cloned materials; source mismatch rejects the treatment. The source GLB and existing editable Blender files are unchanged: standalone GLB and old Blender snapshots do **not** contain this runtime material. The JSON, runtime code and scene configuration must accompany it. A metadata-only preservation simulation carried the parameters and 42 existing detail layers; a full asset rebuild was not run.

Matched first-person screenshots, with activity disabled, each reported 83 draw calls and 851,090 triangles. This adds no draw object or geometry but adds fragment shader work; one view does not establish frame time on other hardware. No performance threshold was changed. Verification passed: 130 JavaScript unit tests, 18 Python tests, production build, formatting, viewer override hashes, 130 open asset records, and five browser tests covering lawn, paving and navigation. The production build reported the existing large-chunk warning.

## Bike rack site screening

The [official UO transportation map](https://map.uoregon.edu/transportation-uo), consulted 2026-11-04, labels F50 and F20 as uncovered bicycle parking. Approximate popup coordinates were transformed to the project coordinate system. Five vertical scene samples around each candidate hit modeled lawn, so no rack was placed there. A12 samples intersected existing Johnson building geometry. A27 was previously screened as covered parking. These samples are limited checks, not proof of clearance or a site survey; map point precision, exact rack configuration, surfaces and present conditions remain unverified. The [generic rack](bike-rack-candidate-2026-11-04.md) remains an unplaced candidate, with its independent GLB and no new Blender snapshot. No map imagery was redistributed.
