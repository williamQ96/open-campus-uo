A source-pinned detail layer adds a simplified glazed frontage, upper cladding, mullions, entry canopy and four illustrative shrubs to the existing `context-b0103` approximate envelope; the campus GLB remains unchanged. The archived [Gary Halvorson / Oregon State Archives photograph](https://commons.wikimedia.org/wiki/File:Tykeson_Hall,_University_of_Oregon,_Eugene_-_DPLA_-_8c33a2d22132624e3de1a4eaf5354e02.jpg) is CC BY 4.0. Its likely north-facing context is inferred from the visible surrounding buildings and [UO's description of the north entrance](https://cas.uoregon.edu/diversity-equity-inclusion); [UO events](https://calendar.uoregon.edu/event/uo-semester-at-sea-study-abroad-visit-info-sessions-tabling-drop-in-hours) also identifies the 13th Street north entrance and portico. This is not a surveyed orientation. The photo is not a runtime texture.

The envelope, glass and canopy dimensions, color, other facades and planting are illustrative; current conditions, species, navigation, accessibility and tree clearance are unverified. Existing tree crowns obscure part of the entrance in the scene. Level remains 1, interiors are untouched. [Before](images/tykeson-north-before.png) / [after](images/tykeson-north-after.png).

## Upper frontage and glazing study, 2026-11-04

The existing attributed 2019 photograph and the [design architect OFFICE 52 project description and images](https://www.office-52.com/work/tykeson-hall-university-of-oregon/) show a glazed lower frontage and two upper rows of openings. The architect describes three interlocking volumes clad in brick, terra cotta and glazing. These sources are used as visual reference only, not as embedded textures; the architect's photographs and drawings are not redistributed. The project's existing mapping of this view to the north-facing scene plane remains an inference, not surveyed orientation.

The source-pinned overlay revises the glazed and light-clad heights, adjusts the existing mullions and upper windows, and adds a second schematic upper row. The existing canopy, four illustrative shrubs, source blockout, roof, campus placement, collision and interior are unchanged. The edited upper front is a stylized approximation: the underlying blockout remains one rectangular mass and does not reconstruct the documented three-volume plan; window counts, proportions, material colors, all other elevations and current conditions remain unverified. Tykeson remains level 1.

[Three-view before/after](images/tykeson-frontage-comparison-2026-11-04.png) uses actual campus context; the front view is cropped and the east view is partly blocked by a tree. A separate [aerial candidate screen](images/tykeson-frontage-aerial-2026-11-04.png) shows the roof junction using the adopted geometry. Three camera-verified views retained 68, 69 and 98 draw calls, and the aerial screen retained 82 before/after. Browser regression covered building selection, entrance records, sampled collision, toon/PBR and the existing performance budget; 160 JS tests, 23 Python tests and build passed. These are not a complete clearance or hardware performance survey.

The [prior specification](../assets/exterior-refinement/tykeson-before-upper-frontage-2026-11-04.json) remains available for rollback. The [additive overlay GLB](../assets/exterior-refinement/tykeson-frontage-overlay-2026-11-04.glb), SHA-256 `1bab415fed0e04bba5753792b78e5a0a3cc4882751c3496a135c20c6cbdafd5c`, contains the facade and four illustrative shrubs, not the base building, terrain, navigation or collision; positions, normals, colors and material colors matched after reimport. The JSON remains the editable procedural source. No new Blender snapshot was made; do not double-load this overlay with the runtime layer. Local only, unpublished.

## Canopy frame and upper cladding study, 2026-11-10

The existing archived Gary Halvorson / Oregon State Archives 2019 photograph (CC BY 4.0) was visually inspected. It clearly shows a framed, subdivided canopy and fine vertical rhythm on the light upper cladding. The complete previous JSON bytes are preserved at `assets/exterior-refinement/tykeson-before-canopy-cladding-2026-11-10.json`, SHA-256 `83dc8689edf6656926631570d704c75b98612834a6ab4ed81897ebfcf30c395a`.

Only original objects 34 and 35 (the two solid canopy plates) were replaced. The refined canopy has slim perimeter frames, 16 transverse ribs and 15 glass-colored infill panels, all within the previous envelope. The existing material is opaque glass-colored shading, not physically transparent glazing. Fine light-colored vertical seams are clipped around both existing upper window rows. All other 50 original objects, including every window and all four shrubs, remain exactly unchanged. Component count increases from 52 to 171 but the existing merged building/vegetation mesh count is unchanged. The canopy remains decorative, not evidence of a verified entrance or accessible route. Materials, spacing and dimensions are interpreted; hidden elevations and the documented three-volume massing are not reconstructed. Level remains 1.

Three targeted unit checks cover preserved originals, canopy bounds, exact object count, upper-window clearance, source hash and unchanged merged mesh count. The older frontage regression still checks its original upper-window rows and shrubs, while the new test explicitly validates the revised canopy. No existing test references the old Tykeson GLB as a current export-equivalence fixture; historical exports are retained.

The browser comparison verifies actual front and oblique player/camera coordinates, Tykeson selection, entrance records, collision probes and zero draw-call increase. Both views stayed at 71 draws before/after, entrance data matched, both viewpoints were collision-clear and no page errors occurred. Four `docs/images/tykeson-canopy-cladding-{front,oblique}-{before,after}-2026-11-10.png` images were visually reviewed: canopy ribs and clipped vertical seams are visible without covering existing window panes; original trees still obscure parts of the oblique view. An initial live-reload interruption was not treated as acceptance; the successful run used a separate no-HMR local server and external test output.

Portable output: `assets/exterior-refinement/tykeson-canopy-cladding-overlay-2026-11-10.glb`, 253,580 bytes, SHA-256 `91bacb470a9625c831e9c5c9c569e428c4affb89cc6c13279150c30fcdde3abc`. The adjacent `.verification.json` records hashes and the portable reproduction command. This GLB contains the facade overlay and four prior illustrative shrubs, not the base building, terrain, navigation, collision or updated Blender source; do not double-load with the active runtime layer. Existing exported files and the original campus GLB remain untouched. Local only, unpublished.
