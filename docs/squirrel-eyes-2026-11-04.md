# Campus squirrel eye detail, 2026-11-04

The existing generic low-poly squirrel now has two dark eye accents, placed on its actual left and right face surfaces and merged into the original mesh. Three-angle isolated [before](images/squirrel-eyes-before-2026-11-04.png) and [after](images/squirrel-eyes-after-2026-11-04.png) views show the modest change; these are enlarged review images, not campus-context screenshots. The animal's shape, pose, routes, counts and colliders are unchanged. LIFE-01 remains level 1; this is not a species identification or a field count.

The [OSU Extension western gray squirrel guide](https://extension.oregonstate.edu/catalog/em-9573-how-help-oregons-native-western-gray-squirrel) describes a regional species and provides general context only. The existing brown model is not presented as that species and no external image or geometry is copied. The base is the project's adaptation of the [Innerscene CC0 squirrel](https://www.innerscene.com/tools/library/3d-parts/tree-squirrel-6499352e); the original CC0 source is preserved, original adaptation is CC BY 4.0, and new code is Apache-2.0.

`apps/web-preview/src/squirrel-detail.js` creates two accents totaling 160 triangles in the same mesh and existing material, using a vertex-color attribute for the eye color. Before mutation it validates the unique source mesh, vertex count, bounding box, material and untextured source and checks ray intersections at the two eye locations. This is a structural check, not an exact runtime source-hash check. The runtime loader applies it once to the shared source before instances are cloned; the default fur color variations still multiply the shared vertex colors. The independent raw source GLB and the original editable Blender snapshot are unchanged. No new Blender snapshot exists; the editable runtime source is the JS generator, and the snapshot does not contain the accents.

[Standalone derived GLB](../assets/animals/campus-squirrel-eyes-v2-2026-11-04.glb), SHA-256 `bbb25b0999eaae4d0c102aecfc9bc4c3718bce5fa79f9ba0eaffc42e2986c148`, contains the model and detail but no actor paths, collisions, animation, or per-instance fur colors. Its exporter pins the source GLB SHA-256 `30d716fa7a576d68ebbe445d1bdfdb0f9282c9c3eced17d39505210c044b4e68`, checks stable inputs, refuses overwrite, embeds the generator hash and compares positions, normals, colors and material after reimport; maximum attribute error was zero. Reproduce from `apps/web-preview` with local Vite at port 5173: `node scripts/export-squirrel-detail.mjs ../../assets/animals/<new-name>.glb`. Do not also apply the runtime generator to this already-refined export.

At default Mid density the eight existing squirrels retain their count; each gets 160 extra triangles, or 1,280 total if all are rendered (High's 20 would add 3,200). Each retains one mesh/draw object; frustum visibility and material instances affect actual calls. The unchanged fixed-view activity-disabled browser test remains below 180 draw calls; it does not assess the extra actor triangles, mobile hardware or frame time. The body positions and normals compared exactly with the source after index expansion, and a mismatched already-mutated source was rejected. Validation: 143 JS tests, production build, formatter, two targeted browser tests in the first check and the squirrel test again after final guard change. The build retains its existing chunk warning. No campus-layout, buildings, interiors or navigation were changed. Local only; unpublished.
