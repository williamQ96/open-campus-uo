# Generic campus scooter refinement — 2026-11-04

The shared procedural scooter has paired wheel supports, a front-fork cross connection, deck edge rails and grip marks, small levers, and a stem collar. The changes are original generic forms, not a depiction of a specific model or a survey of campus vehicles. [UO Transportation Services](https://transportation.uoregon.edu/bike) is context for campus cycling and scooters, not a reference for exact design or placement. No third-party image, logo or model is copied. Original model output is CC BY 4.0; procedural source is Apache-2.0. PROP-03 remains level 1.

[Before](images/scooter-detail-before.png) and [after](images/scooter-detail-after.png) are controlled neutral-scene views, not proof of real-world dimensions. The generated scooter's default rider-inclusive bounds remain [-0.313032, 0.007830, -0.740001] to [0.313032, 2.030001, 0.740001] metres, rounded outwards. Existing rider contact, routes, placement, collisions and the five other generated prop kinds were unchanged. This is an illustrative model; detail sizes, actual vehicle designs and positions remain unverified. The two wheel sets and their small parts are merged into the same mesh and material as the existing scooter.

The procedural JavaScript is the source of truth. The six-kind GLB was regenerated and its imported vertex positions compared against runtime generation for all six kinds. The new `assets/props/campus-props-scooter-2026-11-04.blend` is an editable import snapshot of that GLB, with its SHA-256 recorded in the Blender scene. Reopening the snapshot and comparing all six meshes with a fresh GLB import matched vertex coordinates, face counts and world transforms. Earlier snapshots remain intact; editing a snapshot does not automatically update runtime code. Use the non-overwriting versioned importer with the new GLB and a fresh output name to create another snapshot.

In matched default-density software-rendered scene samples, before and after both measured 246 draw calls; scene triangle counts were 1,051,597 and 1,052,173 respectively with two scooters. These are scene samples, not hardware benchmarks. Existing budget checks continue to require fewer than 180 calls with campus activity disabled. Production build, JS tests, browser activity/navigation, export equivalence and rider contact checks were run; see the accompanying test files. No building interior or campus layout changed.
