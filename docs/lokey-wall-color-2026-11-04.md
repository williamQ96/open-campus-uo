# Lokey Education candidate wall color — 2026-11-04, local only

The existing `roof-74ecc113` Lokey Education candidate now has an illustrative red-brick wall tone across its source-matched vertical walls. The [UO College of Education](https://education.uoregon.edu/coe-campus-and-community) describes the original brick education buildings and their relationship to HEDCO; the [UO 2021 inventory](https://cpfm.uoregon.edu/sites/default/files/uo_building_inventory_202102.pdf) lists Lokey A & B at 1580 Kincaid / 1571 Alder. A [2013 exterior photograph by Visitor7](https://commons.wikimedia.org/wiki/File:Lokey_Education_Building-1.jpg) shows red brick, light window trim and vegetation (CC BY-SA 3.0; reference linked only, no image or third-party geometry bundled). The photo is historical, not proof of current condition or the exact face of this candidate. Color is an artistic approximation, not measured brick or individual masonry.

The project associates this roughly 559 m² LiDAR roof candidate with the complex by approximate nearest roof, not a registered official footprint. The real Lokey complex comprises more than this single candidate. The association, outlines, height, roof, other wings, window placement and estimated north entry remain unverified. The color treatment changes none of those and does not claim a full building reconstruction or level-2 acceptance; inventory remains level 1. No layout, interior, entrance or navigation data was changed.

The [editable wall-color parameters](../apps/web-preview/public/scene/lokey-wall-color.json) use the existing source-pinned `wall-color-patch.js` pipeline: the unique mesh, source colors and vertical normals must match 120 vertices or the patch is rejected before geometry replacement. A real-source browser test verified exactly 120 changed colors, unchanged positions, normals, indices, material and identity, and atomic rejection of an incorrect expected count. The existing modeled entry, click selection, approach and all 534 entrance records matched before and after. The selection and clearance checks concern the model, not real accessibility. The source GLB and existing Blender files remain unchanged, so a standalone GLB or Blender snapshot alone does not include the runtime wall color; the source GLB, patch JSON, presentation configuration and runtime patch code are needed. No new Blender snapshot or standalone color-baked export was produced. Original parameters are CC BY 4.0; code is Apache-2.0.

The existing production chunk-size warning remains. A metadata-only preservation simulation retained all 11 wall patches and the inventory still parsed as 1,081 rows.
