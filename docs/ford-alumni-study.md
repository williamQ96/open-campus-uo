# Ford Alumni Center exterior study — 2026-11-04

The [UO architecture guide](https://expo.uoregon.edu/spotlight/history-uo-architecture/feature/ford-alumni-center) identifies the 2011, four-story Ford Alumni Center near Matthew Knight Arena. The [architect project description](https://www.architectmagazine.com/project-gallery/ford-alumni-center/) describes aluminum panels and glass curtain walls. The [UO image record](https://expo.uoregon.edu/spotlight/history-uo-architecture/catalog/9da82301a5f3f8398f1859129b0395b3) was consulted for overall facade character; photograph by Jeffrey A. Toreson is marked “In Copyright - Educational Use Permitted,” with rights held by the Oregon State Historic Preservation Office; it is used by reference only. No third-party images or geometry are embedded. Original overlay JSON is CC BY 4.0.

`context-b0066` is an approximate context envelope rather than an authoritative footprint. An independently editable, source-hash-pinned overlay of 52 boxes introduces schematic metal cladding, glazing and vertical mullions along the north and east faces, grouped into one render mesh; roof, western and southern facades and the original source geometry remain unchanged. [North before](images/ford-north-before.png) / [after](images/ford-north-after.png); [northeast view](images/ford-east-after.png). It uses stylized opaque glass material; it is not a physical reconstruction or transparent interior.

Four narrow, footprint-adjacent collision rectangles cover the ground-facing facade; no existing route graph segment intersects them within a 0.5 m margin. This is not an accessibility or field-clearance assessment. Existing building position, terrain, vegetation and interiors are unchanged. The source envelope, entrance, wall dimensions and alignment, exact panel arrangement, facade depth, four-story proportions, remaining sides, roof, terrain interfaces and current conditions are unverified. Existing roof and unrefined sides still use placeholder materials. Keep level 1.

`apps/web-preview/public/scene/ford-alumni-detail.json` is the editable runtime source and is linked by SHA-256 from presentation.json; the original standalone GLB and Blender source do not contain the overlay or its collision metadata. Rebuild preservation must carry the overlay and validate the source pin. The candidate adds one render mesh; the existing activity-disabled draw-call budget passed in the browser, but this is not a hardware performance benchmark. No publication of this follow-up is authorized in this batch.

An editable [Blender snapshot](../assets/exterior-refinement/ford-alumni-detail-2026-11-04.blend) holds all 52 boxes and a [standalone GLB](../assets/exterior-refinement/ford-alumni-detail-2026-11-04.glb) holds the same overlay geometry. They are derived from the canonical JSON, whose hash is stored in both. Blender edits do not automatically update the runtime JSON. Neither standalone file includes the original building, ground, roof or the JSON collision rectangles; do not load it together with the runtime overlay. The GLB has one Blender mesh with three material primitives and is a review asset, whereas the runtime merges colors into one render mesh.

Rebuild using Blender 4.5.15 `--background --factory-startup --python-exit-code 1 --python scripts/export-facade-box-overlay-blender.py -- apps/web-preview/public/scene/ford-alumni-detail.json <output.blend> <output.glb>`, then verify with `blender --background <output.blend> --python-exit-code 1 --python scripts/verify-facade-box-overlay-blender.py -- apps/web-preview/public/scene/ford-alumni-detail.json <output.glb>`. The exporter intentionally accepts only unrotated facade boxes using the three supported materials. A Blender GLB round-trip checked 52 source objects and all corners in both directions, maximum spatial error 0.000062 m; [runtime-only overlay](images/ford-overlay-runtime.png) and [independent GLB](images/ford-overlay-export.png) were visually compared in isolation.
