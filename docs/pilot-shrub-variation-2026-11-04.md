# Pilot shrub groups — local partial refinement, 2026-11-04

The existing `planting` mesh contains 40 inferred shrubs, in the original generator's 16-plant band and 24-plant ring. A source-pinned runtime layer adds bounded differences in height, outline and green tone to those two groups while retaining the established low-poly style. Each result remains inside its own original 3D bounding box with the original lowest height; no plant center or scene placement is reassigned, and no tree crown, terrain, collision, navigation or building interior is edited. These are stylized shrub forms, not a claim that a particular species is present. ENV-03 remains level 1.

The [2024 USDA NAIP pilot reference](../data/metadata/naip-2024-reference.json) is dated broad landscape context, not a survey of these individual plants. [Oregon State University's native-plant guide](https://extension.oregonstate.edu/catalog/em-9697-incorporating-pacific-northwest-native-plants-your-water-wise-landscapes) documents regional shrub diversity, and the [UO Old Campus landscape survey](https://cpfm.uoregon.edu/sites/default/files/old_campus_quadrangle_06_12_07.pdf) describes informal planting in that area. Neither establishes the species, shape, exact position or present condition of these particular modeled shrubs. No photo pixels or third-party geometry were incorporated; original geometry/parameters are CC BY 4.0 and code Apache-2.0.

The layer `pilot-shrub-variation.json` is pinned to the base GLB; `src/planting-variation.js` checks the unique mesh, shared material contract, all 40 groups' bounds and index ranges before mutation. It clones the material and geometry, leaves the source and tree canopy material untouched, and supplies valid normals at degenerate poles. A rebuild-preservation guard refuses a changed base hash. The layer adds a float RGB attribute (103,680 raw bytes) plus cloned geometry and runtime/driver overhead; no triangles or draw objects are added. It does not certify existing plant clearance or correct pre-existing inferred placement.

Matched, activity-disabled Toon views show the [band before](images/pilot-shrub-variation-before-2026-11-04.png) / [after](images/pilot-shrub-variation-after-2026-11-04.png) and [ring before](images/pilot-shrub-ring-variation-before-2026-11-04.png) / [after](images/pilot-shrub-ring-variation-after-2026-11-04.png). Band samples each reported 85 draw calls and 824,803 triangles; ring samples each reported 46 calls and 774,440 triangles. These are two local software-rendered views, not a hardware or mobile frame-time benchmark; performance thresholds were not altered.

The [standalone GLB](../assets/vegetation-refinement/pilot-shrubs-varied-2026-11-04.glb) contains the 40 varied shrubs as one indexed PBR mesh in project glTF coordinates; it does not include ground, other vegetation, collision or the full campus. Export and reimport matched all 8,640 positions, normals and colors, plus 12,960 indices exactly. It is not a set of independently editable shrubs and no updated Blender snapshot was produced. The original campus GLB and old Blender files remain unchanged; runtime appearance requires the layer and code. Reproduce a new output with Vite running: `node scripts/export-pilot-shrubs.mjs ../../assets/vegetation-refinement/<new-name>.glb` from `apps/web-preview`; the script refuses to overwrite an existing output.

Validation passed 133 JavaScript unit tests, 20 Python preservation/reference tests, seven browser tests, production build, formatting, viewer hashes and 141 archived asset records. A browser test checks each shrub against original bounds and ground height, valid normals, no shared-material leakage and standalone geometry equality. Existing canopy tests and thresholds were not changed. A full Blender rebuild and device performance test were not performed; the existing build chunk warning remains. Work is local and unpublished.
