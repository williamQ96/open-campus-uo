# Pilot-area bench family — 2026-11-04

Nine existing inferred pilot benches now have slatted wooden backs and armrests. All nine seats and legs and all eleven original lamps retain their existing positions and geometry. A source-pinned vertex patch collapses only the nine original solid back boards; its 72 distinct corner coordinates matched exactly 216 vertices in the archived presentation GLB. The replacement geometry is an independent environment detail layer, not a building asset. It is merged into the verified original wood batch at runtime; this keeps the existing draw-call budget and uses the source material. The source GLB itself is unchanged. Rebuild preservation validates the patch and detail against the exact source hash; a changed model requires review.

The slatted form is a generic interpretation informed by the already archived [2019 Anstett photograph](https://commons.wikimedia.org/wiki/File:Anstett_Hall,_University_of_Oregon,_Eugene_-_DPLA_-_7f05aff2c79e236edd0bed0104b6f145.jpg) (Gary Halvorson/Oregon State Archives, CC BY 4.0); it does not establish these nine benches' real styles or locations. No photo or third-party geometry is embedded. Generated geometry is CC BY 4.0; the reusable code is Apache-2.0. PROP-01 remains level 1.

Four original back elevations differ from the current heightfield-derived values, by up to roughly 0.38 m. Original mesh coordinates were used, not reconstructed heights. One existing bench lies on an illustrative path, and another is near a tree; positions, ground contact, clearance, collision and current conditions require site evidence. No furniture was moved and no navigability or accessibility claim is made.
