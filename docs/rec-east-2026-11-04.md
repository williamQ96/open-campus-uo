# Student Recreation Center east facade — 2026-11-04

The [project architect](https://rdgusa.com/work/project/university-of-oregon-student-recreation-center-expansion-and-renovation) describes the east facade along a major pedestrian and bicycle route and recreation fields. [UO](https://news.uoregon.edu/content/new-expanded-student-rec-center-ready-its-closeup) documents the 2015 expansion and renovation. The [DCI Engineers exterior photograph](https://www.dci-engineers.com/work/university-of-oregon-student-recreation-center) was consulted as reference only; no third-party image or geometry is embedded. Original detail data are CC BY 4.0.

The candidate `roof-af9a4442` is an approximate-nearest-roof match, not a registered footprint. Seven horizontal ray samples at scene height 12 m and glTF z 315–375 m first hit the candidate mesh; the sampled x positions range from approximately -159.93 to -158.15 m along the main span. This supports alignment with a wall in the model, not a field survey or proof that the full candidate is the real east elevation. A source-pinned layer adds schematic opaque glass and three-story-style metal divisions to approximately 50 m of that wall, following its slight slope. [Before](images/rec-east-before-2026-11-04.png) / [after](images/rec-east-after-2026-11-04.png); an existing tree partly occludes the view. The source geometry, terrain, plants, campus layout and interiors are unchanged. The photographed cantilever and supporting columns are not reconstructed. Exact facade, entry, footprint, height, field and current conditions remain unverified; keep level 1.

Four thin collision rectangles conservatively follow the model wall; none of the existing route-graph segments intersects them with a 0.5 m margin. This does not establish field clearance or accessibility. The overlay is merged into the matching source building at runtime only after its 2,406 source-vertex count, identity, material and transform contracts are checked. A browser test verifies that original non-indexed positions, colors and normals remain identical and that the detail is appended to the same selectable building mesh. The original GLB remains unchanged.

The first candidate added a separate draw object and failed the existing <180 draw-call test with 180. It was changed to use the existing source-mesh merge; the unmodified budget test then passed. The matched east overview reported 37 draw calls before and after in this local view, not a hardware performance benchmark. Six browser tests cover source merge, selection in both render modes, Lillis and navigation; 122 Node tests, 14 preservation tests, production build, formatting, 110 open-asset records and viewer hashes passed. A metadata-only preservation simulation validated all 40 current detail layers with the expected 600-source-tree input; a full scene rebuild was not run.

`apps/web-preview/public/scene/rec-east-detail.json` is the editable runtime source, pinned with the base GLB in `presentation.json`. The original GLB and prior Blender assets do not contain the runtime detail. No new Blender or independent GLB was made: Blender was unavailable, and the existing facade snapshot exporter explicitly supports only unrotated boxes, while this layer uses rotated boxes. That exporter must be extended and verified before making a faithful standalone snapshot. No software was installed; all work remains local and unpublished.
