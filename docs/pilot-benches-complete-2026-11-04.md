# Nine complete pilot benches — standalone export, 2026-11-04

The nine existing illustrative pilot benches now have a [standalone GLB](../assets/exterior-refinement/pilot-benches-complete-2026-11-04.glb) with the original metal supports **and** the runtime-refined wooden seats, backs and armrests. This closes the missing-support limitation of the earlier [overlay-only export](pilot-bench-editable-overlay.md). It is an export and reuse improvement; no campus geometry, placements, collision, interiors or rendering changed. PROP-01 remains level 1. The nine positions are inferred, not a field inventory; ground contact, clearance and current conditions remain unverified. The earlier overlay export and Blender snapshot are preserved.

The export contains two meshes in campus glTF Y-up coordinates: 432 indexed support vertices and 6,480 non-indexed wooden vertices. It retains all nine positions in one file, not nine individually pivoted or independently editable meshes; it excludes the campus, lamps, other furniture and navigation. Do not place it over the already-refined runtime benches. The original source GLB and the source-pinned bench JSON plus suppression patches remain authoritative. No complete-bench Blender snapshot was created. To edit individual boxes use the earlier overlay snapshot, with supports still separate; a full Blender reauthoring workflow remains open.

The [Anstett photograph](https://commons.wikimedia.org/wiki/File:Anstett_Hall,_University_of_Oregon,_Eugene_-_DPLA_-_7f05aff2c79e236edd0bed0104b6f145.jpg) by Gary Halvorson/Oregon State Archives (CC BY 4.0) informed the generic slatted vocabulary, not the location or exact appearance of these nine benches. No photograph or third-party model is embedded. The existing original geometry is CC BY 4.0 and exporter code Apache-2.0.

Reproduce from `apps/web-preview` with local Vite on port 5173: `node scripts/export-pilot-benches.mjs ../../assets/exterior-refinement/<new-name>.glb`. The exporter refuses overwrite; verifies the campus GLB, overlay, back and seat suppression pins, nine pairs of original support bounds and their topology; checks input stability during export; and roundtrips position, normal, index and color. The GLB embeds source and generator hashes. Its SHA-256 is `87cf063a883309bb1276aef1840991241b66506b89812564da22e93a9d5ff835`.

[Comparison](images/pilot-benches-complete-comparison-2026-11-04.png): left is the source scene with both suppression patches and runtime overlay, right is the independent GLB; both use the same camera and lights. An automated browser test compared all support and wooden positions and normals against the actual merged scene with maximum error zero, and checked support indices and material parameters. This isolated image does not verify the other eight placements or field conditions.
