# v0.4 — Spawn and building search

The user-selected spawn is the University Street / East 13th Avenue T-junction, local ENU `[-305.469651, 0.824825]`, derived from the two existing centerlines. The nearest building footprint is about 21.70 m away. Character and initial walking views face Erb Memorial Union. Reset clears selection and restores this position and heading.

The main configuration stores spawn and heading preferences. `scripts/rebuild.ps1` writes `public/scene/viewer-settings.json`. These preferences stay downstream. A clean pinned reconstruction verified that geometry and GLB stayed unchanged; a Blender-only save timestamp difference was excluded.

Search covers 63 named buildings, ignoring case and supporting name fragments, multiple words and initials such as EMU and PLC. Keyboard focus suspends movement input. Arrows/Enter or clicking select a result; no-match input does not move the character.

Overview frames the selected building at about 45° with a size/aspect-aware distance and 650 ms transition. Reduced-motion preferences skip the transition; manual controls can interrupt it. Follow and First person preserve position and turn toward the building. Movement/drag resumes normal control; selection remains across view changes.

Selected labels have priority and remain visible when ordinary labels are disabled. Edge labels use an on-screen direction arrow; a gold minimap ring marks the target. Escape closes suggestions, or clears selection outside the input; the clear button resumes searching without teleporting or forcing a campus-wide view.

Seven browser tests and six movement/jump tests passed, including spawn/reset, search, camera framing, labels, settings, typing isolation and narrow widths. An initial CI run exhausted its total timeout on three diagnostic PNG captures (26.02, 27.73 and 30.00 s). Routine preview captures now run only locally; CI retains all behavior assertions and failure traces without increasing the timeout. The subsequent CI passed.
