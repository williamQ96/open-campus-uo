# Generic van hood profile — 2026-11-04, local only

The existing generic campus van now uses a gently sloped front hood instead of a rectangular lower body. The same procedural source is used by runtime instances; existing placement, route, collision envelope, cabin, windows, wheels, trim, colors and other prop types are unchanged. It remains an unbranded illustrative van, not a model of a specific vehicle or a survey of the UO fleet; PROP-02 stays level 1. [UO Motor Pool](https://transportation.uoregon.edu/uo-motor-pool) documents campus vehicle context only, not this design. No third-party photograph, logo or geometry is embedded. [Neutral comparison](images/van-profile-comparison-2026-11-04.png): previous on the left, current on the right. This is not a campus-scene screenshot.

The canonical editable source is `apps/web-preview/src/props.js`. The current six-kind [GLB](../apps/web-preview/public/props/campus-props.glb) was regenerated, and the [preceding GLB](../assets/props/campus-props-before-van-profile-2026-11-04.glb) retained. The van increases from 2,184 to 2,196 positions, with the prior bounding envelope maintained. Browser checks compare all six exported meshes with the generator and compare all five unaffected models' positions, normals, colors and transforms byte-for-byte to the preserved GLB. The existing Blender snapshot predates this and prior profile changes; it is not a current editable snapshot. Blender was unavailable in the earlier documented environment search, so none was created or verified here. Original geometry is CC BY 4.0, code Apache-2.0.

Validation: 139 JavaScript tests, 21 Python tests, targeted browser export/selection/performance and navigation tests, production build, formatting and asset/viewer hashes. The existing fixed overview remains 178 draw calls (<180). The added geometry increases triangles per van, but no hardware frame-time measurement or in-campus van visual review was performed. Existing build chunk-size warning persists. Work remains local and unpublished.
