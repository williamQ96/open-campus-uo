# Rounded cloud volumes — 2026-11-04, local only

The runtime sky now replaces the 90 original flattened rounded-box lobes with 90 low-poly, softly rounded lobes in the same 18 seeded clusters. Each new lobe retains the original lobe's horizontal center and base height; its horizontal extent stays within the prior axis-aligned bounds. Middle lobes are slightly taller for a more layered silhouette. Cloud count, color palette, transparency, material, camera following, drift and reduced-motion behavior remain unchanged. The [US National Weather Service cloud guide](https://www.weather.gov/lmk/cloud_classification) describes the broad rounded-top, flat-base character of cumulus clouds. This is an artistic interpretation, not a statement about Eugene's observed or forecast weather. ENV-07 remains level 1.

EMU draws stayed 71 while triangles fell from 819,257 to 801,257; quad draws stayed 70 while triangles fell from 805,882 to 787,882. The unchanged fixed overview budget test passed at 178 draws (<180). Geometry creation is an extra one-time CPU operation and temporarily holds original and replacement geometry; no hardware frame-time or peak-memory benchmark was performed.

The editable source is [cloud-volumes.js](../apps/web-preview/src/cloud-volumes.js), applied by the campus runtime after the unchanged `createSky`. It verifies the unique existing cloud mesh, source vertex count, material and each source lobe's bounds before building the replacement. The existing `createSky` function alone still returns the earlier cloud shape. The [new standalone GLB](../assets/sky-refinement/campus-rounded-clouds-2026-11-04.glb) contains the replacement cloud mesh only, with 27,000 positions; positions, normals and colors matched the runtime generator on reimport with zero error. It omits the sky dome, camera-follow behavior and drift. On Three.js reimport the consumer must set fog and tone mapping to match runtime; the original [cloud GLB](../assets/sky-refinement/campus-cloud-layer-2026-11-04.glb) is preserved and still passes its original export test. No new Blender snapshot was produced. Original model is CC BY 4.0 and code Apache-2.0; no weather photographs or third-party models are embedded.

Reproduce the new export with local Vite running from `apps/web-preview`: `node scripts/export-rounded-clouds.mjs ../../assets/sky-refinement/<new-name>.glb`. The exporter refuses overwrites, pins all three source modules and checks them again before writing.

Validation passed 143 JavaScript tests, 22 Python tests, seven browser tests including old/new export, reduced motion, navigation and the original draw budget, production build, formatting, viewer hashes, 156 archived source/model hashes and a 1,081-row inventory check. Existing build chunk-size warning persists. No full Blender rebuild or device benchmark was performed. All changes remain local and unpublished.
