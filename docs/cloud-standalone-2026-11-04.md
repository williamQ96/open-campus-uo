# Standalone cloud layer — 2026-11-04

The existing full-campus 18-cluster procedural cloud mesh is now available as a [standalone GLB](../assets/sky-refinement/campus-cloud-layer-2026-11-04.glb). The [National Weather Service cloud guide](https://www.weather.gov/source/zhu/ZHU_Training_Page/clouds/cloud_development/clouds.htm) is contextual reference for lighter upper surfaces and darker undersides, not a source for a particular day in Eugene. No source image or external model is embedded. Original geometry is CC BY 4.0 and procedural code Apache-2.0. This is an export and reuse improvement; the runtime sky and ENV-07's level 1 rating are unchanged.

The one-mesh GLB's 81,000 positions, normals and vertex colors have zero maximum difference from `createSky`; indices, source hashes, identity transform, unlit material, 0.91 opacity and depth-write setting were checked after reimport. A browser pixel comparison with visible clouds under a controlled no-fog, no-tone-mapping scene matched within one channel value. The export omits the separate sky dome, camera-follow behavior and animation/drift, so is not a complete drop-in sky. On Three.js reimport the GLB material defaults `fog=true` and `toneMapped=true`, while runtime uses `false` for both; consumers must configure these explicitly to reproduce the runtime appearance in scenes with fog or tone mapping. Reduced-motion behavior resides in runtime code. Clouds, altitude, season and weather are illustrative, not real observations. No new `.blend` was produced; the editable source remains `apps/web-preview/src/sky.js`.

With local Vite running, use `node scripts/export-clouds.mjs ../../assets/sky-refinement/<new-name>.glb` from `apps/web-preview`. The exporter rejects existing outputs, embeds SHA-256 for `sky.js` and its seeded random-source module, checks inputs remain stable, and validates vertex attributes on reimport. The GLB is not loaded by the current runtime and introduces no additional runtime triangles or draw calls. The prior [campus visual review](images/cloud-campus-after.png) shows the unchanged runtime cloud treatment.

Validation included the standalone geometry and visible-pixel browser comparison, existing cloud reduced-motion/toon/PBR and draw-budget browser check, production build, formatting, viewer hashes and 126 archived asset hashes. No full scene rebuild or new device benchmark was performed.
