# Cloud shading — 2026-11-04

The existing 18 procedural cloud clusters now have a gentle blue-gray underside that transitions to a light upper surface, providing more readable volume across the campus sky. The [US National Weather Service cloud guide](https://www.weather.gov/source/zhu/ZHU_Training_Page/clouds/cloud_development/clouds.htm) describes cumulus as lighter on sunlit surfaces with darker undersides; this is a generic visual interpretation, not observed or forecast Eugene weather. No weather imagery, third-party geometry or texture is embedded. ENV-07 remains level 1.

The same 90 rounded lobes remain merged into one cloud mesh. Their seeded positions, individual geometry, topology, material transparency, drift and reduced-motion behavior are unchanged. The 81,000 position vertices have exactly the same SHA-256 before and after this change. A new per-vertex color attribute shades the existing surfaces and adds 972,000 raw bytes, plus runtime and graphics-driver overhead; it does not add a draw object or triangles. [Sky before](images/cloud-tone-before.png) / [after](images/cloud-tone-after.png); [campus before](images/cloud-campus-before.png) / [after](images/cloud-campus-after.png). The second pair is a controlled campus view, not a field weather observation.

`apps/web-preview/src/sky.js` is the editable source and directly constructs the runtime sky; no separate GLB export is used for this procedural asset. The previous implementation is retained at `assets/sky-refinement/sky-before-shading-2026-11-04.js`. Original code is Apache-2.0. Cloud types, altitude, local conditions, lighting and seasonal coverage remain illustrative. No building interior, campus layout, terrain or tree candidate was modified. Tests cover deterministic positions, color bounds, reduced motion, production build and browser navigation with the existing activity-disabled draw-call threshold. No physical weather or hardware performance claim is made.
