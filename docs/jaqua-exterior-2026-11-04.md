# Jaqua Academic Center exterior — 2026-11-04

The [architect ZGF](https://www.zgf.com/work/1156-university-of-oregon-john-e-jaqua-academic-center-for-student-athletes) describes the three-level 2010 academic center, four public facades and a double-wall facade. The architect's [exterior photograph](https://www.zgf.com/images/P40299_00_printmedium.jpg?w=2000) was consulted to understand its glass-and-metal screen; it is in copyright and is linked as reference only, not bundled or used as a texture. Original overlay geometry is CC BY 4.0.

The existing `context-b0067` is a 38 × 40 m approximate, unregistered placeholder; its identity is an approximate anchor rather than a surveyed footprint. A source-hash-pinned overlay adds four opaque stylized glass faces, vertical metal divisions and three-level horizontal rhythm using 102 boxes merged into one building mesh. The exposed original roof, its details, the ground and trees remain unchanged. The facade is intentionally not transparent: it does not reproduce interior spaces or the actual double-wall construction. Its dimensions, true window spacing, entrance position, roof, site boundaries, ground contact and current condition remain unverified. The architect's image shows a reflecting pool, which the scene does not model and this batch does not invent. Keep level 1.

[Before in campus](images/jaqua-before-2026-11-04.png), [after with card](images/jaqua-after-2026-11-04.png), [context view A](images/jaqua-context-a-2026-11-04.png) and [context view B](images/jaqua-context-b-2026-11-04.png). These are model reviews, not field surveys. Eight thin collision boxes follow the approximate perimeter; none of the existing route-graph segments intersects them with a 0.5 m screening margin. This is not an accessibility or pedestrian-clearance assessment. The added faces are separately selectable as the same stable building ID. The original GLB and interior assets remain unchanged.

`apps/web-preview/public/scene/jaqua-exterior-detail.json` is the editable runtime source; `presentation.json` pins its hash and the original GLB hash. The documented preservation guard handles this overlay list only while both source and output GLB hashes match. Neither the original campus GLB nor a separate Blender/GLB export contains the added layer. The existing generic Blender facade exporter can generate a separate editable snapshot later, but Blender was not found in the current Windows or available WSL environments, so no new Jaqua snapshot or round-trip verification is claimed.

Validation: 119 Node tests, 14 rebuild-preservation tests, production build, 107 open-asset records and viewer hashes; a browser batch checked Jaqua and Ford selection, toon/PBR switching, navigation and the existing activity-disabled draw-call budget. The Jaqua unit test verifies source pins, selection ID, one mesh, collision-box contracts and route screening. The local overview scene reported 22 draw calls before and 23 after with its current view and activity settings; this is not a hardware benchmark. No publication of this batch.

The first local candidate used perimeter collision strips longer than the existing 25 m contract and the viewer correctly rejected it. Each strip was split in two, producing eight valid strips; the viewer and existing tests then passed. No collision limit was changed.
