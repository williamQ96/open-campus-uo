# Context tree trunk refinement — 2026-11-04, local only

The 300 existing inferred context trees in the `campus-trees` batch now have octagonal, flat-shaded trunks in place of square prisms. Each replacement uses the original trunk's center, height, 0.3 m maximum width and color; it remains inside the original square cross-section. The bottom and top of each replacement are open; canopy geometry is not changed. Trees are not moved, and no new planting, collision or navigational geometry is added. This is a modest generic geometric improvement, not a survey or species-specific reconstruction. ENV-02 remains level 1.

The [UO tree resources](https://cpfm.uoregon.edu/trees) and its [2020 tree tour](https://cpfm.uoregon.edu/sites/default/files/tree_tour_august_2020.pdf) document the campus tree collection as broad context. They do not identify these generated trees or verify their present positions, species, height, diameter or color. The context trees were inferred beyond the archived pilot-area aerial. No UO image or GIS geometry was copied; original geometry and parameter data are CC BY 4.0, code Apache-2.0.

`src/context-trunks.js` validates the exact source GLB hash, the unique batch, material, per-tree bark color, dimensions, vertex blocks and triangle indices before replacing any geometry. It retains all canopy positions, normals, colors and triangles; a browser test checks every canopy position and index and a source mismatch rejects without mutation. It reuses the same material and draw object. Original source GLB and Blender files remain unchanged: standalone GLB or Blender alone still shows square trunks; the scene JSON and runtime code are necessary. No new Blender snapshot or baked standalone GLB was made. The rebuild preservation guard carries the source-pinned layer only when the asset hash matches; no full Blender rebuild was performed.

In the matched software-rendered [before](images/context-trunks-before-2026-11-04.png) and [after](images/context-trunks-after-2026-11-04.png) first-person images, activity disabled, draw calls remained 39; triangles rose from 740,292 to 741,492 (+1,200). Replacement buffers add approximately 352,800 bytes relative to the original attributes and index, excluding temporary memory and driver overhead; this view is not a hardware frame-time benchmark. No performance or canopy test threshold was changed. Validation includes 130 JavaScript unit tests, 19 Python tests, production build, formatting, 131 archived asset hashes, viewer hashes and browser tests for source rejection, geometry, toon/PBR and navigation. The build reports the existing large-chunk warning.

Esslinger Hall's official [2025 survey](https://cpfm.uoregon.edu/esslingerhall2025) describes a flat-roofed concrete building attached to McArthur Court and the Recreation Center. The existing candidate `roof-a5ff3d5a` has a 14,501 m² inferred footprint and overlaps the McArthur placeholder by 3,229.85 m²; a separate state-footprint screen intersects multiple source records. This may be a merged candidate, but neither 2D overlap nor the unregistered plan proves a particular boundary. Chiles also overlaps the approximate Computing Center envelope. No architectural detail or identity was added to either candidate pending registered boundary evidence.
