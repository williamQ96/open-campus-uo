# University–Villard shrub batching — 2026-11-04

Twelve existing non-selectable shrubs (four at University Hall and eight at Villard Hall) now share one static vegetation mesh using the existing `mergeLocalDetailKind` helper. Their independently pinned JSON sources, positions, vertex normals/colors, building meshes, selection IDs, collision and original GLB are unchanged. Batch identity checks refuse unexpected building IDs; the existing helper checks static identity transforms and matching material contracts. No asset level changes: these plants remain illustrative level 1, not a species or location survey. See the existing [University](university-hall-refinement.md) and [Villard](villard-east-refinement.md) reference records and licenses; no source photo or geometry is added.

The same 1440 × 1000 activity-disabled initial overview using headless Chrome and ANGLE SwiftShader measured **179 → 178 draw calls** with 1,038,393 triangles in both cases. No existing test threshold changed. A fixed University view measured 109 → 109 calls and 884,259 → 884,899 triangles; a Villard view measured 24 → 24 calls and 611,968 → 612,288 triangles; a third local edge view measured 26 → 25 calls with 736,090 triangles unchanged; a distant Alder view remained 18 calls and 615,247 triangles. The added 640 and 320 triangles are an observed frustum-culling tradeoff when the combined bounds are visible but part of the original separate group was not; this is not an unconditional performance win or a hardware frame-time benchmark.

The identical-camera A/B images in all eight comparisons had **zero changed RGB pixels**: four first-person toon views, three first-person PBR views and the 1440 × 1000 initial overview. Both source and result hashes, image hashes, camera positions, counts and conditions are retained in [machine-readable measurements](../data/metadata/performance/shrub-batching-2026-11-04.json). Examples: [overview before](images/batching-overview-1440-before-2026-11-04.png) / [after](images/batching-overview-1440-after-2026-11-04.png); [University before](images/batching-south-edge-before-2026-11-04.png) / [after](images/batching-south-edge-after-2026-11-04.png); [Villard PBR before](images/batching-pbr-villard-before-2026-11-04.png) / [after](images/batching-pbr-villard-after-2026-11-04.png). The first-person view labelled university in the measurement record is partially obstructed by nearby geometry; the south-edge view shows the shrubs clearly. Results are specific to those views and renderer settings.

Tests compare every position, normal and color in the two source layers, verify unchanged independent building mesh IDs and shadow flags, and compare all 534 entrance records between batched/unbatched pages. Both named buildings remain selectable via search, and actual pointer clicks selected each building in both unbatched and batched scenes. The unchanged fixed-camera <180 browser test, 135 JavaScript tests, 20 Python tests, production build and four targeted browser tests passed. No device-level timing, full campus rebuild or Blender re-export was performed; runtime batching does not change standalone files. Work remains local and unpublished.
