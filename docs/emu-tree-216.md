# EMU vegetation: tree 216

2026-11-03; local and unpublished. Inventory `ENV-01` remains level 1.

A dated comparison of the project's generated tree centers against the archived, public-domain [2024 USDA NAIP pilot orthophoto](../data/reference-images/aerial/naip-2024-pilot-rgb.png) finds tree 216's center on a light open surface near the EMU, with no clear tree canopy at that center. [Aerial screen](images/emu-tree216-aerial.png) marks generated centers; georeference, raster, capture date and SHA-256 are in [metadata](../data/metadata/naip-2024-reference.json). The 0.6 m/px image is not a stem survey; the surface may be roof or paving, and it does not prove present-day conditions. The licensed 2017 EMU photograph is also consistent with an open, landscaped forecourt, but does not identify individual trees.

One inferred tree at ENU approximately (-190.089, -10.770) is suppressed in the runtime rather than moved to an invented location. [Before](images/emu-tree216-before.png) and [after](images/emu-tree216-after.png) are the same controlled campus view; other procedural trees still obscure the building. The original GLB and source Blender are unchanged. The source-pinned patch verifies 218 unique positions and exactly 954 exported vertex matches before applying; a Blender extraction verified no positions shared with another source tree. The [generator](../scripts/extract-emu-tree-216.py) reproduced the patch byte-for-byte using the pinned source blend, input snapshot and runtime GLB. This work suppresses an illustrative rendered element, not a surveyed living tree.

Tree 297 lies near a green/light boundary in the same aerial; its interpretation remains uncertain, so it is unchanged. Other trees, including the unresolved Knight overlaps and procedural vegetation around the EMU, are unchanged. Source tree count remains 600 and visible count is 598, accounting for the earlier tree 273 suppression. The rebuild guard preserves both source-pinned suppression records and validates counts, hashes, duplicate paths and the GLB pin before replacement. Code is Apache-2.0; original patch is CC BY 4.0; USDA imagery retains its public-domain designation.

Validation: production build; 49 JS tests; nine rebuild protection tests; browser tests for Annex selection, landmark search/material modes, visible tree count and draw-call ceiling; visual before/after; Blender 4.5 patch reproduction. Chrome/SwiftShader is not a hardware performance measurement. No building, collision, navigation or interior geometry was modified.
