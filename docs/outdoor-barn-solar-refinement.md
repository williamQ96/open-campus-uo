# Outdoor Program Barn: illustrative solar roof

A reversible source-pinned layer adds nine schematic solar tiles to the modeled `roof-a997a75f` roof. [UO Campus Planning](https://cpfm.uoregon.edu/solar-projects) describes a 2013 photovoltaic installation on the Outdoor Program equipment barn; a [2020 UO sustainability tour](https://cpfm.uoregon.edu/sites/default/files/sustainability_tour_august_2020.pdf) also describes a roof array at the facility. These dated references establish context, not the current panel layout. No third-party image or texture is bundled; original geometry is CC BY 4.0.

The project identifies this roof by approximate nearest-roof matching. Whether this exact modeled roof is the equipment-barn roof, along with the actual panel count, dimensions, orientation and current configuration, remains unverified. Nine tiles are an illustration, not an electrical design or inventory. Their placement was sampled against the existing rendered roof to reduce floating; the source model and geographic footprint remain unchanged. The panels have non-building prop semantics. [Before](images/barn-solar-before.png) / [after](images/barn-solar-after.png). The asset remains level 1.

A reusable, validated optional rotation on exterior primitives supports alignment with sloped surfaces. It does not change existing primitives without rotation and rejects malformed angles.
