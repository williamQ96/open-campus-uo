# 室外景观 L2 核对

景观工作按地点和构件细化。已有资产台账里的 15 组室外 L2 记录保留既有覆盖范围。本表继续核对场景内的道路、场地、雕塑、标识、花坛、植物、楼梯、墙体及同类设施。评级核对平面位置、主要形体和材质、与地形的接合、可编辑来源及场景验证。涉及通行的设施另外核对净空和路线。

| 地点或构件 | 现状 | 证据与待核对内容 |
| --- | --- | --- |
| Pioneer Cemetery 八条主路与东入口 | 已纳入 L2 发布 | 地籍、三期航片和 2024 街景核对砂石道、石墙与 11 级台阶。University Street 至 Memorial Square 的模型路线通过。 |
| Pioneer Cemetery 入口石牌、GAR 纪念碑和首批墓碑 | 已纳入 L2 发布 | 石牌、纪念碑及 23 处多期航片可辨石件已建模。墓碑尺寸采用估算。 |
| Pioneer Cemetery 乔木与玫瑰 | 已纳入 L2 发布 | 首批 121 个估算树冠位置和六处玫瑰位置已配准。边界树种和近邻乔木仍需逐点交叉核对。 |
| Pioneer Cemetery 其余小巷、墓区边石、导览亭和附属设施 | 待细化 | 自助导览图和航片有线索。在被树冠遮挡的位置需查独立图像。 |
| 校园主道路、人行道及广场 | 已有代表性 L2，待逐处复核 | 139 条走廊已有注册铺装。按公共空间逐段核对路缘、过街线、台阶、扶手、道路标识和真实接合。 |
| Gerlinger Field Green、Women’s Memorial Quad、Straub Hall Green | 待逐处配准 | 核对既有 Gerlinger 与 Straub 屋前模型、台阶和地面植被，补上院落与街道之间的设施。 |
| 校方艺术目录中的户外作品 | 待逐项配准 | 先核对作品仍在原位的证据和场景里的尺寸及基座。目录含纪念性雕塑、场地装置和立面装饰。 |
| 校园标识、导览图站、交通与停车标识 | 待逐项配准 | 2024 标识计划提供样式，按当前街景和场地照片确认各位置。 |
| 校园花坛、乔木和林下植被 | 已有代表性 L2，待逐处复核 | 现有植被层和登记树记录作为基线。优先核对已知空地、边界、花坛与通道之间的关系。 |
| 建筑外围台阶、矮墙、栏杆、坡道及其他小品 | 已有代表性 L2，待逐处复核 | 用设计图、同期照片与高程数据按地点核对。 |

资料包括校方指定公共空间和步道清单、艺术目录、标识计划和树木资料。公开的校园范围资料用于建立逐处清单，场景边缘的公园、街道和其他公共景观另以市县资料核查。[Pioneer Cemetery 实施记录](pioneer-cemetery-landscape-review-2026-11-26.md) · [已有道路与铺装](paving-corridors-l2-2026-11-26.md) · [校方公共空间地图](https://cpfm.uoregon.edu/sites/default/files/2024-06/designated-open-space-map.pdf) · [校方雕塑目录](https://expo.uoregon.edu/spotlight/history-uo-architecture/feature/outdoor-sculpture-building-ornamentation) · [校方标识计划](https://cpfm.uoregon.edu/sites/default/files/2024-10/uo-sign-plan-2024.pdf) · [校方树木资料](https://cpfm.uoregon.edu/trees)。
