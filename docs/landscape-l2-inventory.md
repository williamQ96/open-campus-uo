# 室外景观 L2 核对

景观工作按地点和构件细化。已有资产台账里的 15 组室外 L2 记录保留既有覆盖范围。本表继续核对场景内的道路、场地、雕塑、标识、花坛、植物、楼梯、墙体及同类设施。评级核对平面位置、主要形体和材质、与地形的接合、可编辑来源及场景验证。涉及通行的设施另外核对净空和路线。
