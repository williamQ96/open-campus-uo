# Pilot bench editable detail overlay — 2026-11-04

The existing nine generic pilot bench backs, armrests and seat slats are preserved as a 180-object editable Blender snapshot and a one-mesh standalone GLB. Both are generated from `apps/web-preview/public/scene/pilot-bench-detail.json`, SHA-256 `02066062919fefedc83918baef58803f2831949ea7204489e982e901f4eb1590`, and record this source hash and the base asset hash. The [2019 Anstett image](https://commons.wikimedia.org/wiki/File:Anstett_Hall,_University_of_Oregon,_Eugene_-_DPLA_-_7f05aff2c79e236edd0bed0104b6f145.jpg), Gary Halvorson/Oregon State Archives, CC BY 4.0, informed the generic slatted vocabulary; it does not verify these nine locations or exact designs. No photograph or third-party geometry is embedded. Project-generated models are CC BY 4.0; scripts are Apache-2.0. PROP-01 remains level 1.

- `assets/exterior-refinement/pilot-bench-detail-editable-2026-11-04.blend` contains 180 separately editable boxes in Blender Z-up coordinates. It is a snapshot; edits in Blender do not automatically update the canonical runtime JSON.
- `assets/exterior-refinement/pilot-bench-detail-standalone-2026-11-04.glb` contains one combined review mesh in glTF Y-up coordinates. **It is not a complete bench**: original legs and other source furniture remain in the campus GLB, and old seats/backs are hidden at runtime by separate source-pinned suppression patches. Neither original geometry nor suppression is included in this independent overlay export. Do not load both it and the runtime overlay simultaneously.
- The runtime retains the existing JSON and source material merge; these files do not change campus rendering, placement, collision, navigation or performance. As before, positions, ground contact and accessibility are unverified.

Reproduce using Blender 4.5.15 with `--background --factory-startup --python-exit-code 1 --python scripts/export-box-overlay-blender.py -- apps/web-preview/public/scene/pilot-bench-detail.json <output.blend> <output.glb>`. Verify with `blender --background <output.blend> --python-exit-code 1 --python scripts/verify-box-overlay-blender.py -- apps/web-preview/public/scene/pilot-bench-detail.json <output.glb>`. The generator currently accepts only the existing unrotated bench-wood box contract and rejects unsupported shapes/materials; it is not a general JSON importer. Export geometry was compared against all 180 source boxes in both directions after GLB reimport: maximum corner error 0.000069 m, one GLB mesh. [Runtime overlay view](images/bench-overlay-runtime.png) and [export view](images/bench-overlay-export.png) show the same sample detail in isolation. These screenshots do not establish a field survey or the appearance of the omitted legs.
