# Pilot-area paving material — 2026-11-04, local only

The existing `landscape-paving` mesh now receives subtle, world-space joint lines in both Architectural Toon and PBR modes. This applies across the existing authored pilot-area paving mesh, rather than placing individual new slabs: its extent, 5,088 vertices, 3D geometry, heights, grass, building layout, collision and navigation are unchanged. The source mesh spans roughly east -604 to -250 m and glTF south 4 to 193 m, including existing paths around the pilot area; this does not cover every path in the 2 km campus. The design uses a restrained 2.5 m grid and view-distance fade to reduce distant aliasing. It is a generic visual interpretation, not evidence of real joint locations, materials, orientation or construction dimensions. ENV-05 remains level 1.

The [2024-06-08 USDA NAIP pilot orthophoto source record](../data/metadata/naip-2024-reference.json) and its [documented open-plaza comparison](plaza-plant-clearance-2026-11-04.md) establish dated broad hardscape context. They do not resolve paving joints or current conditions; no aerial pixels or third-party images are embedded. The reference image is a US public-domain source as recorded in the project attribution; new parameter data are CC BY 4.0 and code Apache-2.0. [Toon before](images/paving-pilot-before-2026-11-04.png), [toon after](images/paving-pilot-after-2026-11-04.png), and [PBR after](images/paving-pilot-pbr-2026-11-04.png) show the same modeled area, not a surveyed surface.

The optional, source-pinned `apps/web-preview/public/scene/pilot-paving-joints.json` identifies one expected mesh, its vertex count and original material; `src/paving-joints.js` applies the shader to cloned toon and PBR materials. Invalid source hash, ambiguous mesh, changed vertex count or material rejects the treatment before it is attached. The source `campus-expanded.glb` and old editable Blender sources are not modified; the stand-alone GLB alone will **not** show these shader joints. The JSON, runtime code and presentation configuration must accompany it. No new Blender snapshot or texture-baked GLB was produced.

The matched local first-person toon screenshots each reported 71 draw calls; the material adds no geometry or draw object, but does add per-fragment shader work, and no hardware or mobile frame-time benchmark was performed. The existing activity-disabled fixed-camera draw-call threshold remains unchanged. Source-match and callback tests, browser toon/PBR and navigation checks, 127 JavaScript unit tests, 17 Python tests, production build, formatting and viewer hashes passed. A metadata-only rebuild-preservation simulation carried the paving parameters and 42 existing detail layers; a full asset rebuild was not run. Project building interiors were not changed.
